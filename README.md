# LifeSol referral program

Anchor program build project. GitHub Actions workflow `LifeSol SBF build (build only)` is manual-only and compiles the SBF binary and IDL; it does not deploy or send transactions.

Source is under `blockchain/`. The configured Devnet program ID is the existing playground deployment; the source declares a separate placeholder ID for a new program. Do not treat this repository build as a verified replacement deployment.
